# Synthetic cover letter first page

- Generated locally with sharp (SVG text rendered to PNG at 1275 x 1650, the
  150 DPI size of a US Letter page). Not copied from any document.
- Use: a stand-in for a green card cover letter first page. Every name, address,
  and date is made up, including "Jane Doe", "John Roe", "Example Hospital",
  and "123 Example Street". Do not replace it with a real letter.
- Checks: the city, the physician specialty, and the marriage date are redacted.
